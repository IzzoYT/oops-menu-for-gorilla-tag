# oops! Menu

### probably shouldn't have pressed that.

**oops! Menu** is a custom Gorilla Tag mod menu designed with simplicity, customization, and chaos in mind.

Built around a clean gray interface, oops! Menu aims to bring a lightweight, organized, and enjoyable modding experience to standalone Meta Quest headsets.

---

## About

oops! Menu is a Gorilla Tag modding project focused on creating a feature-rich menu without unnecessary clutter.

The goal is simple: make something that looks good, feels responsive, and is actually fun to use.

**Project Status:** 🚧 In Development

## Features

The following are planned features, not confirmed working functionality.

- **Clean Gray UI** — Minimalistic grayscale interface.
- **Standalone Quest Support** — Targeting Meta Quest 2 and Quest 3.
- **Organized Categories** — Easily navigate between different modifications.
- **Customizable Settings** — Adjust menu preferences.
- **Lightweight Design** — Focused on responsiveness and performance.
- **Modular Architecture** — Make it easier to add, update, and manage mods.
- **Regular Improvements** — Bug fixes, optimizations, and new functionality.
